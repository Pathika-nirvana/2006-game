# 동네 태권 대전 연결 안내서

이 폴더는 혼자서도 돌아가는 독립 게임입니다. 문방구 오락기에 붙일 때는 "오락기 앞에서 E를 누르면 화면 전체가 오락기 정면 시점으로 바뀌고, 게임이 끝나거나 나가면 원래 화면으로 돌아오는" 방식으로 연결합니다.

## 1. 폴더를 놓을 위치

`assets/games/fighter/` 에 `index.html` 과 `fighter.js` 두 파일을 넣습니다.

이유: 기존 `server.js` 는 `/`, `/index.html`, `/src/`, `/assets/` 만 내려줍니다. `assets` 아래에 두면 서버 코드를 고치지 않아도 됩니다. 실제 서버 복사본에 넣고 불러 보는 시험을 마쳤습니다 (파일 종류 정상, 신호 정상).

## 2. 부모 게임이 할 일

1. 오락기에서 E를 누르면 코인 100원을 차감합니다. 코인 처리는 부모 몫이고, 이 게임은 코인을 다루지 않습니다.
2. 화면 전체를 덮는 덮개를 만들고, 그 안에 `assets/games/fighter/index.html` 을 화면 속 화면(iframe)으로 가득 채워 넣습니다.
3. 열린 뒤 화면 속 화면에 키보드 초점을 줍니다 (`contentWindow.focus()`).
4. 덮개가 열려 있는 동안 부모 게임의 걷기, E 같은 키 입력은 무시합니다. 키 이벤트가 화면 속 화면으로 들어가므로 보통은 자동으로 분리되지만, 초점이 부모로 돌아올 때를 대비한 안전장치입니다.
5. 게임이 `exit` 신호를 보내면 덮개를 지웁니다. 덮개를 지워야 소리와 반복 실행이 멈춥니다.

짧은 완성 예제가 `host_example.html` 에 있습니다. 표시된 구간을 그대로 옮기면 됩니다.

## 3. 주고받는 신호

게임이 부모에게 보내는 신호 (`window.parent.postMessage`):

| 종류 | 내용 | 언제 |
|---|---|---|
| ready | 최고 점수 | 게임이 켜졌을 때 |
| exit | 최고 점수 | 제목 화면에서 Esc 또는 "나가기" |
| score | 점수, 끝까지 깼는지 | 도전이 끝났을 때 (전부 깼거나 게임 끝) |
| state | 일시정지 여부 | 일시정지를 켜고 끌 때 |

모든 신호에는 `source: 'arcade-game'`, `game: 'fighter'` 가 들어 있습니다.

부모가 게임에 보내는 신호 (`iframe.contentWindow.postMessage`, 반드시 `source: 'arcade-host'` 포함):

| 종류 | 효과 |
|---|---|
| pause / resume | 멈춤 / 다시 진행 |
| mute / unmute | 소리 끔 / 켬 |
| focus | 키보드 초점 다시 받기 |
| reset | 제목 화면으로 되돌리기 |

## 4. 화면 방식

기본은 오락기 정면 시점입니다. 위에 간판, 가운데 모니터, 아래에 조이스틱과 버튼이 있고 키를 누르면 버튼이 눌립니다. 주소 끝에 `?bezel=0` 을 붙이면 간판과 조작판 없이 모니터 화면만 꽉 채웁니다. 어떤 창 크기에서도 화면 비율(320 대 224)은 유지됩니다.

## 5. 용량과 기타

- 전체 약 80KB 입니다. 그림은 코드로 그리고 소리는 합성음이라 외부 파일이 없습니다. 10MB 제한에 한참 못 미칩니다.
- 서버가 하는 일이 없으니 멀티플레이 방과 상관없이 각자 화면에서만 돌아갑니다.
- 최고 점수는 브라우저 저장소에 남습니다.
- 사용자가 준비한 그림이나 에셋은 건드리지 않았고, 이 게임의 그림은 전부 새로 만든 것입니다.

## 6. 게임 내용 요약

- 캐릭터 3명: 한결(균형), 다온(빠름), 철웅(묵직함)
- 무대 2곳: 새싹 태권도장, 아파트 옥상
- 1인 도전: 상대 3명을 차례로 이기면 끝 (마지막 상대는 내 캐릭터의 색만 다른 모습). 지면 계속 여부 화면.
- 2인 대전: 한 키보드에서 둘이서
- 방식: 실제 태권도 겨루기처럼 점수 싸움입니다. 한 판 60초, 3판 2선승. 몸통 2점, 회전 몸통(뒤차기) 4점, 얼굴 3점, 회전 얼굴(뒤후려차기) 5점. 점수차 12점이면 바로 승리, 동점이면 골든 포인트(먼저 득점).
- 정타: 상대가 발을 내는 순간, 발을 거두는 순간, 다가오는 순간, 휘청이는 순간을 맞추면 +1점에 큰 피해. 얼굴 정타는 바로 케이오.
- 허점: 돌려차기 계열은 차는 동안 얼굴이, 옆차기와 찍어차기는 몸통이, 뒤차기 계열은 등이 비어 있어서 그 부위를 맞으면 정타입니다.
- 헛방 대가: 모든 기술은 헛치면 회수가 늘어납니다. 뒤차기와 얼굴 돌려차기는 휘청이고, 뒤후려차기는 넘어지며 상대에게 감점 1점이 갑니다.
- 체력 게이지도 있어서 시간 종료 시 동점이면 체력이 많은 쪽이 이깁니다.

조작 (1인)
- 방향키 이동. 뒤로 누르면 막기, 아래는 숙이기, 위를 누른 채 차면 얼굴 차기.
- S 왼발 차기, D 오른발 차기. 어느 기술이 나가는지는 거리(먼 거리, 중간, 가까움)와 어느 발인지로 정해집니다.
  - 앞발: 먼 거리 앞차기, 중간 돌려차기, 가까우면 짧은 돌려차기 (위+차기는 얼굴 앞차기, 얼굴 돌려차기, 찍어차기)
  - 뒷발: 먼 거리 발붙여 돌려차기, 중간 뒷발 돌려차기, 가까우면 뒤차기 (위+차기는 얼굴 버전, 가까우면 뒤후려차기)
  - 앞 방향+차기: 앞발은 옆차기, 뒷발은 발붙여 돌려차기. 뒤 방향+차기: 앞발은 앞차기, 뒷발은 뒤차기(받아차기).
- Q 풋워크: Q+앞 스텝 인, Q+뒤 스텝 아웃, Q만 누르면 스위치(앞발과 뒷발 바꾸기). 딛는 도중에 차기로 이어갈 수 있습니다.
- A 훼이크: 평소에는 거짓 동작(방향에 따라 바디 드롭, 물러나는 척, 발 들기). 차기 준비 중에 누르면 차기를 접습니다.
- 강한 기술: S와 D를 같이 누르면 거리에 따라 강한 기술이 나갑니다. 먼 거리 뛰어 옆차기, 중간 돌개차기, 가까우면 내려찍기. 위를 같이 누르면 얼굴 버전(뛰어 얼굴 옆차기, 돌개 얼굴 차기). 맞으면 쓰러뜨리지만 헛치면 대가가 큽니다. 한 발을 누른 뒤 3프레임(0.05초) 안에 다른 발을 눌러도 강한 기술로 바뀝니다.
- 스텝 차기: Q(풋워크)를 누르면서 또는 딛는 도중에 S나 D를 누르면 더 멀리 나가고 더 세지만 헛치면 더 크게 빕니다. 이름 앞에 "스텝"이 붙습니다.
- Q 특수기(힘을 받는 기술, 강하지만 헛치면 휘청): 백스텝 뒤 뒷발은 카운터 뒤차기, 백스텝 뒤 앞발은 회축, 스텝 인 뒤 뒷발은 턴차기, 스텝 인 뒤 앞발은 돌진 옆차기.
- 나래차기: 앞발 돌려차기 직후 반대발을 바로 누르면 돌려차기가 빠르게 이어집니다.
- 훼이크 방어: A는 평소엔 훼이크. 상대 공격이 닿기 직전(약 1~5프레임 전)에 누르면 흘리기가 되어 이어지는 반격이 매우 셉니다. 조금 이르게(약 6~17프레임 전) 누르면 방어가 되어 피해가 살짝만 줄어듭니다. 닿는 순간에 누르면 늦습니다.
- 한 키보드 2인 대전(시험용): 1P는 방향키와 Q A S D, 2P는 I J K L 이동과 U O P ; (풋워크, 훼이크, 왼발, 오른발)
- Esc 일시정지(제목에서는 나가기), M 소리 끔. 게임 패드도 인식합니다.

## 6-2. 온라인 대전 (각자 자기 컴퓨터에서)

온라인에서는 두 사람 모두 똑같은 키(방향키와 Q A S D)로 조작합니다. 게임은 서로 입력만 주고받고, 양쪽 화면이 똑같이 계산하는 방식이라 서버가 싸움을 계산할 필요가 없습니다.

부모 게임(바깥 화면)이 해야 할 일은 세 가지입니다.
1. 두 사람이 같은 방에 들어오면 양쪽 게임 화면(iframe)에 시작 신호를 보냅니다. 한 명은 side 0, 다른 한 명은 side 1이고, seed 는 두 사람이 같은 숫자(아무 숫자나 서버가 한 번 정해서 둘에게 알려 줌)여야 합니다.
   `iframe.contentWindow.postMessage({ source: 'arcade-host', type: 'net-start', side: 0, seed: 12345, delay: 4 }, '*')`
2. 게임 화면이 보내는 `{ source: 'arcade-game', game: 'fighter', type: 'net-send', msg: ... }` 를 받으면, msg 를 내용 그대로 상대 쪽 서버를 거쳐 상대 게임 화면에 전달합니다.
   `iframe.contentWindow.postMessage({ source: 'arcade-host', type: 'net-msg', msg: msg }, '*')`
3. 상대가 연결을 끊으면 `{ source: 'arcade-host', type: 'net-leave' }` 를 보냅니다.

그 밖에 게임이 부모에게 알려 주는 것: `net-result`(한 판 결과, winnerSide 와 youWon), `net-desync`(두 화면의 계산이 어긋남, 정상이면 오지 않음), `net-end`(온라인 모드 종료), `exit`(나가기).

delay 는 입력을 몇 프레임(1프레임은 약 0.017초) 늦춰서 서로 맞추는 값입니다. 한쪽 방향 통신 시간(핑의 절반)이 짧으면 4, 길면 6에서 8을 쓰세요. 값이 너무 작으면 통신이 늦을 때 화면이 잠깐 멈췄다 가고, 너무 크면 조작이 둔해집니다.

시험해 보려면 `host_net_example.html` 을 서버로 열어 보세요. 한 화면에 두 게임을 놓고, 가짜 통신 지연을 넣어 온라인 대전을 흉내 냅니다.

## 7. 알려진 한계

- 캐릭터와 무대 그림은 코드로 그린 임시 도트입니다. 나중에 직접 그린 그림으로 바꾸는 작업이 필요합니다.
- 소리는 합성음 흉내입니다.
- 서로 다른 기기에서의 장시간 시험, 휴대폰 터치 조작은 해 보지 않았습니다.
