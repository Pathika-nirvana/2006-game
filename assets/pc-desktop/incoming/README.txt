이 폴더에 그림 파일을 넣으면 게임 안 PC방 컴퓨터의
"내 문서 > Incoming" 폴더에 그대로 나타납니다.

- 지원하는 파일: webp, png, jpg, jpeg, gif, bmp
- 파일 이름은 한글이어도 됩니다. 이름 순서(숫자 순서)로 보입니다.
- 파일을 넣거나 빼고 나면 별도 작업 없이 게임 안에서 폴더를
  다시 열기(또는 새로 고침)만 하면 반영됩니다.
- 운영 서버(Render)에서도 보려면 이 폴더의 파일을 GitHub에
  함께 올려야 합니다.
- 용량 안내: 한 장당 500KB 안쪽의 webp를 권합니다. 장수가
  많아지면 처음 열 때 불러오는 데 시간이 걸립니다.
- 이 README.txt는 게임 안에 나타나지 않습니다.
