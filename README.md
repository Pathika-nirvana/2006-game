## A40 먹기와 음식 소지

- 음식과 인물을 따로 겹치던 먹기를 완성된 인물+손+음식 PNG로 교체했습니다. 원화에 입 벌림, 한 입, 입 닫기/볼·턱 표정 두 단계를 포함합니다. 대기 상태를 반복하는 방식으로 먹기를 대신하지 않습니다.
- 전용 4종과 공통 1종을 유지합니다. 빨강/파랑 슬러시도 별도 행을 사용하며, 종이컵 고증을 유지합니다.
- 음식 소지 상태에서 정면 서기, 걷기 8프레임, 앉기, 점프를 연결했습니다. 걷기는 기존 다리 8프레임을 보존하고 음식·손을 함께 그린 상체와 결합합니다. 개별 무릎·다리를 늘이거나 관절을 조합해 새 걸음을 만들지 않습니다.
- 소지 앉기/점프는 각 한 포즈를 게임의 물리 위치에 맞춰 사용합니다. 준비/착지까지 별도 4프레임을 새로 그린 것으로 표시하지 않습니다.
- 새 인물 PNG는 `assets/characters/carry-eat/`의 6개 시트. 한 장당 120셀, 셀128×128, 발 anchor(48,124). 캐릭터의 실제 표시 높이는 기존 약44 게임 픽셀을 유지합니다. 큰 셀의 여백은 음식과 앉은 다리가 잘리지 않도록 둔 것입니다.
- 멀티 상태에 들고 있는 음식 종류를 추가해 친구에게도 같은 음식 소지/먹기가 보이도록 연결했습니다. 정원은 12명 그대로이며 서버 물리 모듈은 변경하지 않았습니다.
- 영상/GIF는 새로 만들지 않습니다. `verification/carry-states.png`, `eating-frames.png`, `mouth-detail.png`로 확인합니다. 이전 버전의 영상은 이번 ZIP에서 제외합니다.

- 발 기준은 모든 프레임 `(48,124)`. 전체 셀은 96×128, 표시 상자는 36×48 게임 픽셀이며 실제 서 있는 몸의 높이는 약 44픽셀입니다. 프레임별 비율 늘이기는 하지 않습니다.
- 캐릭터 코드·PNG·manifest 분리. 기존 NPC 이미지도 외부 PNG로 옮겨 내용 보존.
- 실제 음식은 기존 구매 품목 렌더러가 그립니다. 시트 속 예시 컵은 지웠습니다.
- 로컬/원격 캐릭터별 모션 시계를 분리. 기존 방 정원 12명과 서버 물리를 유지.
- 과거 배치 실험 편집기의 버튼과 L 단축키를 비활성화했습니다. 협동 놀이기구 조작 패널은 유지합니다. 비교/롤백 UI는 추가하지 않았습니다.

## 검증 결과와 한계

`verification/검증보고서.md`를 먼저 보세요. Node 서버의 12인·협동 물리 테스트와 실제 게임 스크립트의 Canvas 실행 검증을 통과했습니다. 브라우저 UI/CSS/음향, 서로 다른 실제 기기 12대의 인터넷 동기화는 미검증입니다.

현재 ZIP의 정지 캡처는 **원래 게임 코드의 update/render를 Node VM + native Canvas에서 실행한 결과**입니다. 브라우저 플레이 화면을 녹화한 것으로 표시하지 않습니다. 테스트용 DOM 대역은 배포 코드에 포함되지 않습니다.

## 파일

- `index.html`: 기존 세계·상점·주민·옥상·멀티 클라이언트
- `src/characters.js`, `src/character-atlas.js`: 선택·모션·렌더러
- `assets/characters/manifest.json`, `manifest.js`: 동일 내용의 데이터/직접 실행용 JS
- `assets/characters/*.png`: 실제 사용 시트
- `art/source/`: 이미지 생성으로 만든 편집 원본 6장
- `art/head-mask-*.png`: 복장 간 공유하는 얼굴·머리 픽셀 마스크
- `tools/build-atlases.cjs`: 정규화·팔레트·포장 재생성
- `docs/캐릭터_표준.md`, `docs/제작_기록.md`: 제작 규격 및 프롬프트
- `docs/handoff/`: 이번 작업에서 읽은 원본 인수인계 문서
- `verification/`: 정지 PNG 캡처·검증 기록

## 개발용 검사

게임 서버 실행과 무관한 개발용 도구만 `npm install`로 설치합니다.

```
npm run test:coop
npm run test:share
npm run test:characters
npm run test:engine
npm run test:npc
npm run test:scale
npm run test:palette
npm run test:render
npm run art:build
```

`test_multiplayer_12.js`는 별도 서버가 필요합니다. 한 터미널에서 `PORT=33125 node server.js`, 다른 터미널에서 `node tests/test_multiplayer_12.js`. Windows PowerShell은 `$env:PORT=33125; node server.js`.

시트를 바꿀 때 셀/anchor/manifest를 함께 검증하세요. JSON을 바꾸면 `manifest.js`도 같은 데이터로 갱신해야 합니다. 라이브 GitHub/Render에는 업로드하지 않았습니다.
