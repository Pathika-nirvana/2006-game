# 《2006년.. 90년대생의 회상》 — A27 친구 초대 링크 웹 배포

## 이 파일의 역할
- A26의 게임 맵·문방구·분식집·PC방·놀이터 물리·옥상 감상 기능을 포함한 **12인 웹서버형 A27** 프로젝트.
- 서버는 HTTP로 게임을 제공하며 같은 주소의 `/ws`에서 WebSocket으로 연결.
- 닉네임과 방코드를 입력하고 입장 후 **친구 초대 링크 복사**를 누르면 `https://실제주소/?room=방코드` 형태로 공유 가능.
- 초대받은 친구는 그 주소만 열고 닉네임 입력 → **친구 방에 입장** 버튼을 누르면 됨. 친구는 Node.js 설치 불필요.
- 서버가 재시작되거나 호스팅이 잠들면 방 접속 상태와 놀이터 물리는 초기화됨. 게임 월드 수정 내용도 사용자별 로컬 저장이며 공유 월드 데이터 아님.

## 실제 공개 URL 만들기 (Render)
1. 이 ZIP을 풀고 **내용물을 GitHub 저장소의 루트**에 올린다 (`render.yaml`도 루트에).
2. [Render Dashboard](https://dashboard.render.com/) → **New → Blueprint** → 해당 GitHub 저장소를 연결한다. `render.yaml`이 12인 웹서버 서비스 설정을 생성한다. Blueprint를 쓰지 않을 경우 **New → Web Service**를 만들고 Node, `npm install --omit=dev`, `npm start`, `/health`를 설정한다.
3. Render가 배포를 끝내면 `https://...onrender.com` 형태의 **실제 게임 주소가 생성**된다. 사용자별 주소는 지금 정해져 있지 않다.
4. 주소에 접속하고 닉네임 입력 → 방 입장 → **친구 초대 링크 복사** → 친구에게 보내기. 방당 최대 12명.
5. 게임을 새로 업데이트할 때는 GitHub 저장소에 갱신된 파일을 push하고 Render 배포를 확인하면 된다.

**무료 서비스 주의**: 장시간 트래픽이 없으면 잠들어서 다음 접속 때 재시작이 필요하고, 메모리·사용량 제한이 있다. Render 서비스가 재배포되면 연결된 플레이어는 다시 접속해야 한다. 채팅과 닉네임은 로그인 보안이 없는 소규모 친구 초대용 체험이며 방코드는 비밀번호가 아니다. 공개 커뮤니티용 모더레이션·스팸방지·관리자 기능은 없음.

## 컴퓨터에서 미리 시험하기
Node.js 22+ 설치 후:
```bash
npm start
```
`http://localhost:3000` 접속. 친구는 이 주소로는 접속할 수 없고 **호스팅 배포된 공개 HTTPS 주소**가 필요하다.

테스트:
```bash
npm run test:coop
npm run test:share
```
