# 《2006년.. 90년대생의 회상》 A46 검토 빌드

첨부 인수인계 ZIP의 A37을 수정한 로컬 검토본입니다. 새로운 게임을 만든 것이 아닙니다. 그래픽 승인본이나 공개 배포 완료본으로 간주하지 마세요.

## A46 화면 구도

거리의 화면 보행선을 40단위 내려 하늘과 건물을 더 보여주고 단색 도로 확장을 제거했습니다. docs/A46_화면구도.md 참조.

## A45 상점 거리 1차 적용

문방구·골목·분식집·PC방 상가의 새 PNG를 게임에 연결하고 출입/주문/의자 좌표를 이동했습니다. `docs/A45_상점거리.md`를 먼저 확인하세요. 양끝의 기존 학교·주택가 연결부는 아직 다른 그림 밀도가 남아 있습니다. 전체 맵 완성본은 아닙니다.

실제 게임 스크립트 렌더: `verification/map-stationery.png`, `map-snack-pc.png`. 새 상점 앞에서 E로 기존 상호작용을 사용할 수 있습니다. 실행은 `node server.js` 후 표시된 로컬 주소를 여세요.

## A44 캔버스 축소 손실 수정

게임 좌표480×270과 인물 크기는 유지하고, 메인 캔버스를1440×810으로 바꿔 직접 그립니다. 작은 완성 화면을 사후 확대하지 않습니다. 기존 기본/음식/주민 PNG26장은 A43과 같고 원화를 새로 생성하지 않았습니다. 상세 내용과 한계는 `docs/A44_캔버스해상도.md`를 보세요.

현재 게임 캡처는1440×810이며 검수판은 `verification/render-detail.png`, `render-in-game.png`입니다. 아래 A38~A43의 크기·렌더 설명은 각 버전의 기록입니다.

## A43 그림체 통일과 어린이 크기

주민 원화를 기준으로 플레이어의6복장 기본 동작과 음식 소지·먹기 원화를 다시 그렸습니다. 인물별 추출·발 정렬·공유 머리 픽셀·일반/음식 공통 팔레트로 포장합니다. 어른은 A42의 커진 크기를 유지하고, 플레이어와 주민 아이는 실제 서기 높이 약50픽셀(어른약64)로 맞췄습니다. 건물은 그대로입니다.

현재 기본 시트는128셀/1024×512, 음식 시트는128셀/1024×1920입니다. 발anchor(48,124)는 같습니다. 상세 규격·제작 방식은 `docs/A43_그림체통일.md`가 현재 기준입니다. 아래의 A38~A42 설명은 당시 버전 기록입니다. 정지 검수판은 `verification/unified-characters.png`, `unified-food-motions.png`, `unified-in-game.png`입니다.

## A42 인물 비율

사용자의 최종 지시에 따라 어른을 줄이지 않고 약18% 확대하고, 플레이어는 약33%, 다른 아이는 약34% 확대했습니다. 건물은 그대로입니다. 플레이어 표시 셀은64px(원본의 정확히1/2), 일반 어른78px, 아이 주민71px, 할머니74px입니다. 투명 여백을 제외한 실제 서기 높이는 아이 약59/어른 약64게임 픽셀입니다.

음식 소지·먹기와 일반 모션이 같은 표시 높이를 공유합니다. 기존 원화·동작·물리는 보존하고 E/이름표/말풍선 위치를 옮겼습니다. 현재 크기는 `docs/A42_비율조정.md`가 기준이며 아래의 과거 버전 설명은 당시 기록입니다. 검수 PNG는 `verification/proportion-review.png`입니다.

## A41 동네 주민

- 기존 14개 주민 역할을 새 PNG로 교체했습니다. 걷기8, 정면대기4, 인사3, 생활동작4, 앉기2, 점프2, 측면대기1을 포함합니다.
- 경비 아저씨의 빗자루·수첩, 이웃의 빨래, 배달원의 직사각 철가방 등 역할별 소품을 포함합니다. 어른/아이의 상대 크기와 발 접지를 구분했습니다.
- 주민 동선·대화·상점·일과 ID를 보존했습니다. 플레이어 선택은 기존6복장 그대로입니다.
- 원본 `art/npc/`, 게임 시트 `assets/characters/npc/`, 공통 렌더러 `src/npc-atlas.js`로 분리했습니다. 규격과 검수 중 수정은 `docs/A41_주민_제작기록.md`를 보세요.
- 정지 PNG 검수판: `verification/npc-roster.png`, `npc-actions.png`. 영상은 만들지 않습니다.

## A40 먹기와 음식 소지

- 음식과 인물을 따로 겹치던 먹기를 완성된 인물+손+음식 PNG로 교체했습니다. 원화에 입 벌림, 한 입, 입 닫기/볼·턱 표정 두 단계를 포함합니다. 대기 상태를 반복하는 방식으로 먹기를 대신하지 않습니다.
- 전용 4종과 공통 1종을 유지합니다. 빨강/파랑 슬러시도 별도 행을 사용하며, 종이컵 고증을 유지합니다.
- 음식 소지 상태에서 정면 서기, 걷기 8프레임, 앉기, 점프를 연결했습니다. 걷기는 기존 다리 8프레임을 보존하고 음식·손을 함께 그린 상체와 결합합니다. 개별 무릎·다리를 늘이거나 관절을 조합해 새 걸음을 만들지 않습니다.
- 소지 앉기/점프는 각 한 포즈를 게임의 물리 위치에 맞춰 사용합니다. 준비/착지까지 별도 4프레임을 새로 그린 것으로 표시하지 않습니다.
- 새 인물 PNG는 `assets/characters/carry-eat/`의 6개 시트. 한 장당 120셀, 셀128×128, 발 anchor(48,124). 캐릭터의 실제 표시 높이는 기존 약44 게임 픽셀을 유지합니다. 큰 셀의 여백은 음식과 앉은 다리가 잘리지 않도록 둔 것입니다.
- 멀티 상태에 들고 있는 음식 종류를 추가해 친구에게도 같은 음식 소지/먹기가 보이도록 연결했습니다. 정원은 12명 그대로이며 서버 물리 모듈은 변경하지 않았습니다.
- 영상/GIF는 새로 만들지 않습니다. `verification/carry-states.png`, `eating-frames.png`, `mouth-detail.png`로 확인합니다. 이전 버전의 영상은 이번 ZIP에서 제외합니다.

## 실행

Node.js 22 이상에서 이 폴더를 열고 `npm start`, 브라우저에서 http://localhost:3000 접속. 게임 실행에는 npm 패키지 설치가 필요하지 않습니다.

`index.html`을 직접 열면 혼자 실행할 수 있습니다. 이때도 `src/`와 `assets/`를 함께 두어야 합니다. 멀티플레이는 Node 서버로 실행하세요.

← → 걷기 / Space 점프 / C 앉기 / E 출입·주문·상호작용 / F 먹기 / I 가방 / B 또는 V 캐릭터 / T 시간 / R 날씨.

## 이번 변경

- 플레이어 남학생 1명·여학생 1명, 각각 사복 2벌·빨강/검정 품띠 도복 1벌.
- 6개 PNG 모두 같은 셀·발 기준·애니메이션 명세 사용. 대기 4 / 측면 걷기 8 / 앉기 4 / 점프 4 / 먹기 4. 뒤돌아보기 원형 8셀도 제작 파일에 포함.
- 남학생의 기존 서기 대체용 앉기·점프·먹기를 전용 프레임으로 교체.
- 복장별 얼굴·머리의 지정 픽셀을 기본 캐릭터와 공유. 세 복장을 한 팔레트로 양자화하고 무작위 디더링 사용 안 함.
- 발 기준은 모든 프레임 `(48,124)`. 전체 셀은 96×128, 표시 상자는 36×48 게임 픽셀이며 실제 서 있는 몸의 높이는 약 44픽셀입니다. 프레임별 비율 늘이기는 하지 않습니다.
- 캐릭터 코드·PNG·manifest 분리. 기존 NPC 이미지도 외부 PNG로 옮겨 내용 보존.
- 실제 음식은 기존 구매 품목 렌더러가 그립니다. 시트 속 예시 컵은 지웠습니다.
- 로컬/원격 캐릭터별 모션 시계를 분리. 기존 방 정원 12명과 서버 물리를 유지.
- 과거 배치 실험 편집기의 버튼과 L 단축키를 비활성화했습니다. 협동 놀이기구 조작 패널은 유지합니다. 비교/롤백 UI는 추가하지 않았습니다.

## 검증 결과와 한계

`verification/검증보고서.md`를 먼저 보세요. Node 서버의 12인·협동 물리 테스트와 실제 게임 스크립트의 Canvas 실행 검증을 통과했습니다. 브라우저 UI/CSS/음향, 서로 다른 실제 기기 12대의 인터넷 동기화는 미검증입니다.

현재 ZIP의 정지 캡처는 **원래 게임 코드의 update/render를 Node VM + native Canvas에서 실행한 결과**입니다. 브라우저 플레이 화면을 녹화한 것으로 표시하지 않습니다. 테스트용 DOM 대역은 배포 코드에 포함되지 않습니다.

## 파일

- `index.html`: 기존 세계·상점·주민·옥상·멀티 클라이언트
- `src/characters.js`, `src/character-atlas.js`: 선택·모션·렌더러
- `assets/characters/manifest.json`, `manifest.js`: 동일 내용의 데이터/직접 실행용 JS
- `assets/characters/*.png`: 실제 사용 시트
- `art/source/`: 이미지 생성으로 만든 편집 원본 6장
- `art/head-mask-*.png`: 복장 간 공유하는 얼굴·머리 픽셀 마스크
- `tools/build-atlases.cjs`: 정규화·팔레트·포장 재생성
- `docs/캐릭터_표준.md`, `docs/제작_기록.md`: 제작 규격 및 프롬프트
- `docs/handoff/`: 이번 작업에서 읽은 원본 인수인계 문서
- `verification/`: 정지 PNG 캡처·검증 기록

## 개발용 검사

게임 서버 실행과 무관한 개발용 도구만 `npm install`로 설치합니다.

```
npm run test:coop
npm run test:share
npm run test:characters
npm run test:engine
npm run test:npc
npm run test:scale
npm run test:palette
npm run test:render
npm run art:build
```

`test_multiplayer_12.js`는 별도 서버가 필요합니다. 한 터미널에서 `PORT=33125 node server.js`, 다른 터미널에서 `node tests/test_multiplayer_12.js`. Windows PowerShell은 `$env:PORT=33125; node server.js`.

시트를 바꿀 때 셀/anchor/manifest를 함께 검증하세요. JSON을 바꾸면 `manifest.js`도 같은 데이터로 갱신해야 합니다. 라이브 GitHub/Render에는 업로드하지 않았습니다.
