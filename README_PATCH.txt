2006 A93 패치 · 그림판에서 그림 저장 · 그림 뷰어에서 바탕 화면 설정
버전 0.93.0 · 2026-11-08 19:22 (한국시간)
기준: 이미 적용한 A92 패치 위에 덮어씌우는 패치입니다. (A86부터 A92까지 순서대로 적용한 소스가 기준입니다.)

적용 방법
1. 압축을 풀어 나온 파일을 소스 폴더(index.html이 있는 곳)에 그대로 덮어씌우세요. 새 그림이나 소리 파일은 없습니다.
2. node server.js 로 켜거나 index.html을 열고, 게임 안 PC방 컴퓨터로 들어가세요.
3. 브라우저에서 예전 화면이 보이면 Ctrl+F5로 새로 고침하세요. (스크립트 뒤의 캐시 번호를 A93으로 바꿔 두었습니다.)

무엇을 보면 되나
- 바탕화면의 그림판을 열어 그림을 그리고 저장을 누르세요. 파일 이름과 형식(PNG, JPEG)을 정하는 창이 뜹니다. 아래의 진짜 내 컴퓨터에도 내려받기를 켜면 다운로드 폴더에도 파일이 받아집니다.
- 내 문서를 열어 내 그림 폴더로 가면 저장한 그림이 파일로 있습니다. 더블클릭하면 그림 및 팩스 뷰어로 열립니다. 고른 뒤 자세한 정보의 삭제로 지울 수 있습니다.
- 그림 뷰어 아래쪽 줄 맨 오른쪽의 바탕화면 단추(또는 그림 위 오른쪽 단추 메뉴, 키보드 B)를 누르면 바탕 화면 배경으로 설정하는 창이 뜹니다. 위치는 확대, 가운데, 바둑판식 중에서 고릅니다.
- 내 문서의 Incoming 폴더나 내 그림 폴더 왼쪽 그림 작업 칸의 바탕 화면 배경으로 설정도 같은 일을 합니다.
- 바탕 화면에서 우클릭, 화면 등록 정보를 열면 고른 그림이 (그림) 이름으로 보이고, 위치를 바꿀 수 있습니다. 그림판의 배경 화면으로 단추도 이제 같은 방식입니다.

- 고친 파일: index.html, src/xp-apps.js, src/xp-shell.js, src/pc-system.js, src/xp-desktop.js, assets/pc-desktop/xp-extras.css, package.json, README.md, tools/source-files.json

참고
- 월드맵, 캐릭터 비율, 이동키, 기존 멀티플레이, 오락기 입력, 배경음악, PC 조작 중 주변 게임음 차단은 건드리지 않았습니다.
- 저장한 그림은 이 브라우저 안에 남습니다(12장까지, 한 장 약 220KB까지). 같은 브라우저에서 다시 켜면 그대로 있고, 다른 자리나 친구 화면에는 나타나지 않습니다. 브라우저 방문 기록을 지우면 같이 지워지니 아끼는 그림은 내려받기로 파일을 받아 두세요.
- 예전 그림판이 한 장 저장해 둔 그림은 이전 그림.png라는 이름으로 내 그림 폴더에 옮겨집니다.
- 그림 뷰어의 인쇄, 저장, 삭제, 편집 단추는 예전처럼 제한 안내가 나옵니다.
- 내려받기 파일 이름이 한글일 때 제 시험용 브라우저에서는 download라는 이름으로만 나왔습니다. 실제 크롬에서는 확인하지 못했습니다.
- 운영 서버(깃허브, Render)에는 올리지 않았습니다.
- 자세한 내용은 RELEASE_A93.md를 보세요.

되돌리는 방법
- 패치 전체를 취소하려면 A92 패치를 다시 덮어씌우세요. 저장해 둔 그림 목록은 브라우저 안에 남지만 A92에서는 쓰지 않습니다.
